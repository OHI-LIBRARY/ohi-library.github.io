# OSIM Library Loan System
نسخة أولى لواجهة طلب استعارة مبنية على بيانات Excel.

- 4336 سجل كتاب في `data/books.json`
- بحث بالعنوان/المؤلف/الموضوع/التصنيف/ISBN
- نموذج طلب استعارة
- مدة 14 يومًا + تجديد 7 أيام
- لوحة مسؤول تجريبية

## المرحلة التالية
ربط الطلبات بـ Google Sheets + Apps Script لإضافة الموافقة/الرفض، تسجيل التواريخ، الإشعارات، والتجديد.
